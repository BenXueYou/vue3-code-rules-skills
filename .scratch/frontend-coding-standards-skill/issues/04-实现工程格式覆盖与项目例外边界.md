# 04 — 实现工程格式覆盖与项目例外边界

**要构建的内容：** 让项目负责人可在明确授权后接入或覆盖工程格式，同时确保默认不迁移存量文件；为团队阶段提供受控、可追责的项目级规则例外机制。

**阻塞于：** 01 — 提炼并验证 Vue 3 规则真源；02 — 实现试点前端编码规范 Skill。

**状态：** ready-for-agent

- [ ] 只有用户明确要求“接入规范”或“覆盖工程格式”时，才允许对齐工程格式与静态检查配置。
- [ ] 未经明确授权的普通代码生成或修改任务不会改动工程格式配置。
- [ ] 工程格式覆盖默认不自动格式化存量文件。
- [ ] 如果配置变更会影响全库校验，或工具无法限定至触及文件，系统会先说明影响；全库迁移必须获得单独授权。
- [ ] 项目级例外可以新增规则例外或将规则降级为 GUIDANCE，且必须包含项目原因与负责人。
- [ ] 项目级例外不能修改、删除或改写团队全局规则真源。
