# 01 — 提炼并验证 Vue 3 规则真源

**要构建的内容：** 将现有前端编码规范的 Markdown 文字条款与 PDF 截图示例共同提炼为 `0.0.1` 的结构化 Vue 3 规则真源，使维护者能够追溯每条规则的来源、强度、状态和例外，并获得由真源生成的只读阅读视图。

**阻塞于：** 无——可以立即开始。

**状态：** done

- [x] 规则真源包含版本、唯一规则 ID、ACTIVE/PENDING 状态、MUST/VERIFY/GUIDANCE 强度、适用场景、规则内容、判定条件、例外和来源信息。
- [x] Markdown 文字条款与 PDF 截图示例均可追溯到对应规则。
- [x] “必须/不允许”映射为 MUST，“推荐/统一/采用”映射为 GUIDANCE，含义或适用条件不明确的内容标记为 PENDING。
- [x] 可从同一真源生成标明版本与规则状态的只读阅读视图。
- [x] 规则真源通过结构验证，包括必填字段、规则 ID 唯一性、状态枚举、强度枚举和来源信息。
