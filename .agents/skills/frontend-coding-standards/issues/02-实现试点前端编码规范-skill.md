# 02 — 实现试点前端编码规范 Skill

**要构建的内容：** 让 Vue 3 开发者能够显式优先、并可由任务描述自动触发地使用前端编码规范 Skill；Skill 在生成或修改代码时读取 ACTIVE 规则，只对当前触及代码施加约束，并保护未触及的存量代码。

**阻塞于：** 01 — 提炼并验证 Vue 3 规则真源。

**状态：** ready-for-agent

- [ ] Skill 的适用范围限定为 Vue 3 的 Vue SFC、TypeScript、JavaScript、CSS、Less 和 SCSS。
- [ ] 开发者可通过显式调用启用 Skill，相关 Vue 3 任务也可自动匹配该 Skill。
- [ ] Skill 只应用 ACTIVE 规则，遇到 PENDING 规则时不擅自执行，并在需要时请求澄清。
- [ ] Skill 仅修改本次新增或直接触及的代码；未触及的存量规范债务仅报告，不自动整改。
- [ ] 当前规则与项目自动化配置冲突时，当前规则仅在触及代码中优先执行，不触发存量文件修改。
