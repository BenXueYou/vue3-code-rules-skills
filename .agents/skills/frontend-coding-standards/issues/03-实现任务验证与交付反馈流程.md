# 03 — 实现任务验证与交付反馈流程

**要构建的内容：** 当 Skill 完成 Vue 3 代码生成或修改任务后，开发者可以获得与当前改动相关的既有项目校验结果，以及统一、可审阅的试点交付反馈。

**阻塞于：** 02 — 实现试点前端编码规范 Skill。

**状态：** ready-for-agent

- [ ] Skill 会先识别目标项目已有的格式化、lint、类型检查和测试能力。
- [ ] Skill 只运行与当前改动相关的既有校验，不为验证临时安装依赖或修改工程配置。
- [ ] 校验结论明确区分通过、失败和未执行，并记录失败或未执行原因。
- [ ] 每次实际启用 Skill 的交付反馈包含规则版本、显式或自动触发状态、应用的规则类别、校验结果、冲突和 PENDING 项。
- [ ] 反馈内容能够作为试点成熟度与后续版本升级的记录。
